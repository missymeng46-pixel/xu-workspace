序 XU · 个人工作空间
====================

这是一个本地运行的个人工作台。你的任务、项目、财务、内容和笔记默认只保存在自己的电脑上。

第一次使用
----------
1. 解压整个文件夹，不要只拖出其中一个文件。
2. 不要直接双击。请按住 Control 键点击“启动序.command”，再选择“打开”。
3. 如果仍提示“Apple 无法验证”，请按照“Apple无法验证时请看这里.txt”处理。
4. 浏览器会自动打开工作台。
5. 点击左下角个人资料右侧的“•••”，修改自己的昵称和工作空间名称。

启用 AI 自动分类（可选）
----------------------
1. 准备自己的 DeepSeek API Key。
2. 右键点击“配置DeepSeek.command”，选择“打开”。
3. 输入密钥时终端不会显示字符，这是正常现象。
4. 配置完成后重新启动工作台。

不配置 DeepSeek 也可以使用任务、项目、财务、内容和每日小票；收件箱可以点击“手动整理”自己选择去向。

同一 Wi-Fi 手机访问
----------------------
1. Mac 和手机连接同一个信任的 Wi-Fi。
2. 在 Mac 工作台打开“设置”，点击“显示二维码和访问码”。
3. 手机扫描二维码，再输入 Mac 上显示的6位访问码。
4. 如果 macOS 询问是否允许 Python 接受传入连接，请点击“允许”。

Mac 需要保持开机，启动工作台的终端窗口也不能关闭。关闭终端后，手机访问码会失效。请勿在咖啡店、酒店等公共 Wi-Fi 中开启。

数据位置
--------
工作数据会自动创建在：data/xu.sqlite3

需要迁移电脑时，请备份整个 data 文件夹。DeepSeek 密钥保存在隐藏文件 .env 中，不要把它发给别人。

停止工作台
----------
关闭启动工作台时打开的终端窗口即可。

常见问题
--------
- 已经有其他本地网页在运行：序 XU 会自动选择可用端口，无需手动处理。
- 页面没有更新：重新双击“启动序.command”。
- 双击脚本没有反应：按住 Control 键点击脚本并选择“打开”。
- 提示“Apple 无法验证”：这是 macOS 对网络下载脚本的保护，不是工作台损坏。请查看同文件夹中的单独说明。
- 手机扫码后打不开：确认手机和 Mac 在同一 Wi-Fi，并关闭手机的移动网络代理或 VPN 后重试。
